# 数据与联网说明

作者：**Kerwin**

浮词读取所选播放器的进程、系统媒体会话、主窗口辅助功能数据及相关曲目／歌词缓存。播放器数据库以只读方式读取。

不登录音乐账号，不索取密码，不使用账户 Cookie 查询歌词，不下载音乐音频，不以屏幕截图识别播放状态。

缺少本地歌词或必要元数据时，会向公开歌词／曲目接口发送请求，可能包含歌名、歌手、时长或曲目 ID。因此软件并非完全离线，也不能描述为任何数据都不发送。

没有播放日志上传、遥测或自动更新检查。关于页中的链接会由系统浏览器或邮件程序打开。

## 数据位置

- 解压版 / 源码：程序目录中的 `appearance.json`、`lyric_cache`、`sync_state.json`、`sync_events.jsonl`。
- 安装版：`%LOCALAPPDATA%\BetterLyrics`，由安装目录中的 `installed.flag` 识别安装模式。
- 卸载默认保留用户数据。如需完全清理，可在退出后自行移除上述用户数据目录。

日志可能包含歌曲、歌手、路径、播放位置和外观。提交 Issue 前先检查、脱敏，不要上传整个播放器缓存。

仓库的演示文字与背景为原创。效果图由隔离演示场景生成，磨砂图展示实际系统合成效果，不采集日常桌面用于宣传。

“昆明理工大学在读”仅为作者简介，不表示学校参与或背书。
